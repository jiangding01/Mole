# Mole for Mac —— 设计稿交接说明(致 Claude Code)

本文件随 `Mole.dc.html` + `support.js` 一起交付。请先读这份,再动代码。

---

## 0. 这是什么 / 不是什么

- **是**:一份**高保真交互设计原型**,用来定稿视觉语言、信息架构、交互流程、动效。所有页面、状态、动画都真实可运行。
- **不是**:生产代码。它跑在一个叫 **DC(Design Component)** 的原型运行时上(`support.js` 就是这个运行时,**不要改它、不要照它的模式写生产代码**)。
- **所有数据都是编造的**(进程、应用、磁盘树、历史、指标)。生产版必须替换成真实的系统 API 调用。见 §5。

开发时的正确姿势:把它当**规格说明书 + 像素级参考**,用你选定的原生技术栈(SwiftUI / Tauri / Electron 等)**重新实现**,而不是把这个 HTML 直接打包。

---

## 1. 架构速览(原型侧)

- 单文件 `Mole.dc.html`:顶部 `<helmet>`(字体/keyframes/body reset,含 `a`/`a:hover` 链接色)→ 模板(`<x-dc>` 内的标记)→ 逻辑类 `class Component extends DCLogic`。
- 渲染模式:逻辑类的 `renderVals()` 返回一个大对象,模板用 `{{ 路径 }}` 取值;`sc-for` / `sc-if` 做循环与条件。
- **样式全部内联**(no CSS class),主题靠 CSS 变量。这是原型运行时的要求,生产版用你自己的样式体系即可,别被这点束缚。
- 状态机核心:`this.state.page`(当前模块)+ 各模块自己的子状态(如 `cleanState: idle/scanning/confirm/executing/done/empty`)。

## 2. 设计语言(必须保留的部分)

**气质关键词:精致、克制、可信、专业但不冰冷。** 不要营销式空话("一键加速""深度焕新"),所有文案说清后果("将把 129 项移入废纸篓,共 8.9 GB")。

**字体三分工:**
- 英雄数字(可清理体积、健康分、大读数)→ **Instrument Serif**(衬线,有设计感)
- 单位 / 路径 / 索引 / 英文微标签 / 技术信息 → **JetBrains Mono**(等宽仪器感)
- 中文标题、正文 → **思源宋体 / 思源黑体**(Noto Serif SC / Noto Sans SC)

**主题系统:**
- 三套明暗 LOOK(`LOOKS`):`Ink`(暖墨深色,默认)、`Onyx`(冷墨深色)、`Paper`(暖象牙浅色)。深/浅由设置的"外观"(自动/浅色/深色)驱动。
- 六个模块各一主题色相(`THEMES`),用于该页高亮、强调按钮、图表主色、焦点环:
  - 智能扫描 `#D3A24A` 品牌金 ・ 清理 `#3C93B0` 青蓝 ・ 软件 `#8E72CE` 紫
  - 优化 `#B0702E` 铜橙 ・ 分析 `#C86B49` 橙陶土 ・ 状态 `#4CA07C` 绿(健康语义)
- 切页时背景有一层 <8% 的主题色氛围渐变,400ms 交叉淡入。
- 语义色独立于主题色:成功=绿、警告=琥珀、危险=红。**风险标识必须"颜色+图标+文字"三通道齐全**,不能只靠颜色。

**卡片:** 大圆角(统一 15px)、半透明材质、1px 内描边、极轻阴影。

## 3. 三个信任承诺(产品灵魂,不可删)

任何"动手删用户文件"的地方都必须兑现:
1. **删之前看得见** —— 破坏性操作前展示完整的将删列表 + 总大小,可逐项取消。
2. **删了能找回** —— 一律移入废纸篓(不是永久删),文案强调可恢复。
3. **删过有记录** —— 每次操作写入历史页。

风险三级:`safe`(默认勾选)/ `caution`(琥珀徽标、默认不勾、hover 说明原因)/ `info`(不可勾、洞察卡形式)。白名单命中项灰化 + 盾牌图标。

## 4. 焦点环(Focus Ring / 光谱环)——核心动效资产

- 智能扫描 / 清理 / 优化 / 分析扫描 共用**同一个 canvas 引擎**(逻辑类里的 `initOrb()` / `loop()`)。
- 状态机:静息呼吸 → 扫描(刻度均衡器 + 扫描头掠过 + 环心读数上翻)→ 等待确认 → 执行(甜甜圈弧段随进度放空/点亮)→ 完成(收束定格)。
- 颜色自动取当前模块主题色。
- **Reduce Motion**:设置里的"减弱动态效果"开启时,粒子/转场停用、只保留数字补间。生产版必须实现同款降级(并尊重系统 `prefers-reduced-motion`)。
- 动效原则:单次反馈 ≤200ms、转场 ≤400ms、环为环境动画不阻塞点击。

生产实现建议:用 Metal / Canvas / SwiftUI Canvas 复刻,关键是"扫描→结果"的形态连续过渡(环收束成甜甜圈/结论),别做成两个割裂的画面。

## 5. ⚠️ 全是假数据 —— 生产必须接真实 API

原型里这些都是写死的 mock,开发时逐一替换:

| 模块 | mock 位置(逻辑类字段) | 真实来源 |
|---|---|---|
| 清理分组/条目 | `CLEAN_GROUPS` | 实际扫描 ~/Library/Caches、日志、浏览器、开发者工具、残留… |
| 已装应用 | `APPS` | `/Applications` + `~/Applications` + bundle 元数据 + 残留路径推断 |
| 更新 | `UPDATES`(逻辑类)+ `_upds`(运行态) | **Homebrew cask**:`brew outdated --cask` + `brew upgrade --cask <token>`(v1.1 唯一可一键更新的来源);App Store / Sparkle / Electron 仅**检测 + 引导跳转**,Mole 不代为执行 |
| 启动项/服务 | `LOGIN` / `SVC` | LaunchAgents / LaunchDaemons / 登录项 |
| 优化任务 | `OPT_TASKS`(21 项,id 与 CLI catalog 一致) | CLI catalog 注册表;**全部免管理员**(robot 模式无 sudo,任务内部自动降级)。协议**不提供时长估计**,设计里不得出现「约 N 秒」 |
| 进程持续告警 | `_proc[].alert`(分钟数) | `status --watch` 的 `process_alerts`(默认阈值 100%、持续窗口 5 分钟,均可配),含触发进程与持续时长 |
| 大小未知 | `CLEAN_GROUPS` 中 `size:0, unknown:true` 的条目 | 协议 `bytes: null`(尺寸测量有时间预算,超时项为 null)。**禁止显示为 0 B** |
| 磁盘树 | `ensureDisk()` 生成 | 真实递归扫盘(需 FDA 权限) |
| 系统指标 | `initStat()` / `statTick()` 随机游走 | IOKit / sysctl / powermetrics 等真实传感器 |
| 进程表 | `_proc` 数组 | 真实进程列表(注意:进程 CPU% 多核可 >100,原型钳到 99) |
| 历史 | `HISTORY` | 本地操作日志持久化 |

**权限**:深度扫描需要 **完全磁盘访问(FDA)**;深度维护/风扇电池养护需要**管理员后台 helper**。Onboarding 第 2/3 步和设置·权限中心已设计好授权引导与状态卡,按那个交互实现真实检测与跳转。

> **2026-08 修正**:当前 21 项养护任务**全部无需管理员授权**。设计稿里已移除任务卡上的「管理员」徽标,只保留「只读」徽标(`login_items_audit`、`disk_verify`)。管理员授权弹层(`optAuth`)的代码与视觉**保留待用**,但现阶段不会被任何任务触发 —— 等 Phase 3 后台助手落地、出现真正需要它的新任务时再挂回去。

## 5b. 2026-08 迭代增补(本次交付的新设计)

### 「大小未知」边界态(协议 `bytes: null`)
三处呈现,已在稿中定稿:
1. **清理确认列表行**:尺寸列显示「大小未知」(mono、10.5px、`--text-mute`),hover tooltip「测量超时,删除后按实际释放量记录」;**项仍可勾选删除**。
2. **分组 / 总计**:总计只累加已知项;总计旁出现微文案「另有 N 项大小未知」(10.5px 大写微标签风格,仅 N>0 时渲染)。
3. **智能扫描洞察卡**:大数字位置显示 `—`、单位隐藏,body 文案照常。此态由 DC prop `insightUnknown` 驱动(默认 false),便于走查两种状态。

**红线**:任一「大小未知」项都不得显示为 `0 B` / `0.00 GB`。

### 更新 tab 的来源分流
- 来源徽标各自配色:Homebrew `#C9862F`、App Store `#4C8FD8`、Sparkle `#8E72CE`、Electron `#7C90A8`;徽标 hover tooltip 说明该来源能否在 Mole 内更新。
- 行动作按来源分流:**Homebrew** = 「更新」主按钮(可执行);**App Store** = 「前往 App Store」跳转;**Sparkle / Electron** = 「打开应用检查更新」跳转。跳转类一律用次级描边按钮 + 外链箭头,与可执行动作在视觉上分级。
- 「全部更新(N 项)」**只作用于 Homebrew 项**,N = brew 可更新数;左侧另注「另有 M 项需前往来源更新」。
- 行内状态机:`idle → running(spinner「更新中…」)→ done(绿色「已更新」,1s 后行淡出)`或 `failed`。失败行:边框转红 + 行内错误卡(brew stderr 摘要)+ 「重试」按钮;重试成功即走 done。
- **待实现的边界态**:无 brew 环境时 Homebrew 来源整体缺席,空态文案不提 brew。

### 持续高 CPU 告警(`process_alerts`)
- 火焰图标**只绑定持续告警**(`p.alert`),不再由瞬时 CPU 触发;hover tooltip = 「持续高 CPU · 已持续 N 分钟 > 100%」。
- **进程详情弹窗**(§9.6 用户 App / 系统进程变体)在进程树下方插入一条琥珀告警条:图标 + 文字 + `ALERT` 微标签(颜色+图标+文字三通道)。
- 告警进程在查看时已退出 → 沿用 §9.6「已退出」极简卡。
- **明确不做**:进程表按告警自动重排序(保留用户排序权),仅图标标记。

### 全局快捷键(设置·通用)
- 录制交互:「未设置」→ 点击进入录制态(「按下组合键…」+ 脉冲点提示行,esc 取消)→ 捕获组合后显示 `⇧⌘M` 样式(mono)+ 右侧清除按钮。
- 必须包含修饰键才被接受;与系统快捷键冲突时,行下方出现琥珀提示「与系统快捷键「聚焦搜索」冲突,建议换一组」(冲突表见逻辑类 `CONFLICT`)。
- 默认为空;作用 = 唤起/隐藏 Mole 主窗口。

### 诊断报告导出流(设置·高级 + 菜单「运行诊断」)
- 进行中:按钮内 spinner + 「导出中…」,按钮文字转主题色。
- 完成:底部居中 toast「已导出到 ~/Desktop/Mole-诊断-YYYY-MM-DD.zip」+ 「在 Finder 中显示」+ 关闭 ×,6 秒自动消失。
- 失败:同位置红色 toast + 「重试」(原型里每第 3 次导出走失败态,方便走查)。
- 报告内容说明固定一句:「导出运行日志与系统摘要,不含文件内容。」

### 应用自更新 sheet(Sparkle · 设置·关于 + 菜单「检查更新」)
- 入口:设置·关于「检查更新 → 有新版本 1.3.0 ›」与菜单栏「检查更新」共用同一 sheet。
- 内容:版本号对比(`1.2.0 (412) → 1.3.0 (437) · 18.4 MB`)、更新说明列表(要点加粗、修复项用灰点)、下载进度条(百分比 mono)。
- 按钮:主「下载更新」→ 下载中(禁用态 + spinner)→ 「重启并安装」;次「稍后」;弱「跳过此版本」(左下,不与主动作争夺注意力)。
- 跳过 / 安装均落一条 toast 回执。

## 5c. 确认页条目层(2026-08-15 r2 / r3 迭代,规则以此节为准)

变更明细见 `CHANGELOG-2026-08-15.md`(r1)、`CHANGELOG-2026-08-15-r2.md`、`CHANGELOG-2026-08-15-r3.md`。下面是必须延续到生产的**规则**。

### 数据规模与 0B 目标
- 确认页按真机规模呈现(约 1624 项),分组卡 + 贡献条 + 每组首屏 12 项 + 「再显示 50 项」渐进披露。
- **0B 目标不进入 GUI 清理计划**:空目录零收益且会被应用重建,GUI 既不展示也不删除(不删的东西无需展示,不违背信任承诺①)。CLI TUI 行为不变。
- 稿中 0B 的分隔线 / 置灰 / 「全 0B 组」变体保留为**兜底态**(`ZERO_IN_GUI` 常量),协议若回传 0B 项仍能正确渲染。

### 条目行形态(双行 + 单行回退)
- **主行**语义名 12.5px/500/`--text`;**副行**路径 10.5px mono/`--text-mute`。语义名来自 GUI 侧「知名路径 → 名称」映射表。
- **映射不到就只显示路径一行**(字号 12px、色阶 `--text-dim`),**绝不编造名称**。
- 两种形态共用 `min-height:42px` 居中行盒,混排时左右两端仍成列。
- 路径副行**从头部截断、保留尾段**(`direction:rtl; unicode-bidi:plaintext` + 省略号),完整路径挂 `title`。
- **性能红线**:确认页曾出现「30fps 永动动画 × 数百行文本测量」的布局风暴,行高定高与渐进披露是修复的一部分;**任何新形态不得引入常驻动画**(锁定行等均为静态徽标)。

### 行内动作
- 每行右端常驻两个动作(`opacity .45`,hover 升 1):**在 Finder 中显示**、**加入白名单**(盾牌)。
- 加白名单**不移除条目**:灰置 + 「已加白名单」徽标 + 取消勾选 + 不计入统计,**可撤销**。
- 盾牌 tooltip 必须写明后果:影响 **CLI 与 GUI 的所有后续扫描**(对应 `robot whitelist add --mode clean`)。

### 两级「不可删」的信息分工(不可混用)
| | 页顶进程守卫条 | 行级锁定 (`item.blocked_by`) |
|---|---|---|
| 含义 | 段级「**整段没扫**」 | 「**扫到了但此刻不可删**」 |
| 字节数 | **不给**(没扫就不承诺) | **照常显示** |
| 形态 | 蓝灰信息条,可展开列出应用,可关闭 | 锁图标替代复选框 + 琥珀徽标「应用打开中 / 系统占用」 |
| 交互 | — | 不可勾选、不计入已选;hover 说明「退出 <应用> 后重新扫描即可清理」 |

聚合父行被锁时**全部子行继承锁定**,父子各自保留徽标与体积。

### 同质子项聚合(限定条件,不可放宽)
1. 仅限**同一容器 / 同一父目录**;跨语义聚合仍是红线(禁止把 45 条不同东西并成「用户缓存」一条)。
2. 父行必须显示**子项数 + 总量**。
3. **默认收起**;展开后子行一级缩进 22px、各自体积、各自行内动作、逐项可勾。
4. 父行勾选 = 全子联动(三态);父行自身 `size = 0`,不参与统计,杜绝重复计数。

### 选择预设
确认条右侧 **全选 · 清空 · 推荐**,「推荐」= 协议 `default_selected`(safe 勾 / caution 不勾);当前选择等于推荐集时字色高亮。

## 6. i18n(重要:原型是临时方案)

- 原型用一个 `TR` 字典(中→英)+ 渲染后遍历 DOM 文本节点替换的 `translateDOM()`。**这是原型 hack,生产别照抄**。
- 但 `TR` 字典本身是一份**很有价值的中英对照术语表**(几百条 UI 文案),生产做正式 i18n(`.strings` / `.xcstrings` / i18next 等)时,直接拿它当词表起点。
- 目前支持中/英两语,语言在设置·通用切换;需可扩展更多语言。
- 数字/日期要按 locale 格式化(原型里扫描时间戳 `M月D日` → 英文 `Jul D` 已示范)。

## 8. 验收自检(沿用设计基线)

- 任一屏 5 秒内看懂"现在发生了什么、我能做什么"。
- 所有破坏性操作前可见完整将删列表 + 总大小。
- 风险信息 颜色+图标+文字 三通道齐全。
- 深浅双模式对比度达标(WCAG AA)。
- Reduce Motion 有完整降级。
- 窗口 980→1600pt 拉伸不破版(最小 980×640,默认 1200×760)。
- 气质:像专业工具,不像"清理垃圾软件"。
- **0B 目标不进入 GUI 清理计划**(不展示也不删除);段级「没扫」不给字节数,行级「此刻不可删」必须给字节数。
- **映射不到知名路径的条目只显示路径,不得编造语义名**。
- **任一「大小未知」项不得显示为 0 B**(总计也不得把它算成 0 后误导用户)。
- **更新 tab 每行的动作必须与其来源能力一致**:只有 Homebrew 行可以出现「更新」;其余行只能是跳转。
- 优化任务卡上**不出现时长估计**,也不出现管理员徽标(除 Phase 3 后新增的确需授权的任务)。

有拿不准的交互/视觉细节,以 `Mole.dc.html` 实际运行效果为准。

## 9. 设计 Token 速查表(开发直接抄数值)

### 9.1 字体

| 用途 | 字体 | 字重/字号示例 |
|---|---|---|
| 英雄数字(体积/健康分/大读数) | **Instrument Serif** (`--serif`) | 400,44–56px |
| 单位/路径/PID/索引/英文微标签/技术信息 | **JetBrains Mono** (`--mono`) | 400–500,11–13px |
| 中文标题 | **思源宋体 Noto Serif SC** | 600,20–34px |
| 中文正文/UI | **思源黑体 Noto Sans SC** / PingFang SC | 400–600,12.5–14px |

说明文字 13px、退后处理(`--text-dim`);微标签 10.5px 大写 + 字距 .2em(`--text-mute`)。

### 9.2 明暗 LOOK 令牌(CSS 变量)

三套:`Ink`(暖墨,默认深色)、`Onyx`(冷墨深色)、`Paper`(暖象牙浅色)。关键值:

| 令牌 | Ink(默认深) | Onyx(冷深) | Paper(浅) |
|---|---|---|---|
| `--bg`(径向渐变基色) | `#191510→#0a0807` | `#14171c→#08090c` | `#FCF9F3→#EBE1D0` |
| `--surface-solid`(卡片实底) | `#181410` | `#12151b` | `#FCFAF5` |
| `--text` | `#F3ECE0` | `#EEF1F6` | `#2C2216` |
| `--text-dim`(次要) | 白 60% | 白 60% | 墨 64% |
| `--text-mute`(标签) | 白 40% | 白 40% | 墨 44% |
| `--line` / `--line-strong`(描边) | 白 9% / 17% | 白 9% / 17% | 墨 11% / 20% |
| `--chrome`(导航胶囊底) | `rgba(20,17,13,.55)` | `rgba(16,19,24,.55)` | `rgba(255,253,248,.72)` |

深/浅切换:设置·通用「外观」= 自动(跟随系统)/ 浅色 / 深色。深色下 `Ink`/`Onyx` 由 DC 的 `look` prop 选择。

### 9.3 模块主题色(六相,`THEMES`)

每个模块一个色相,含 `a`(主)、`b`(高光,按钮渐变到)、`ink`(强调件上的文字色)。

| 模块 | `a` 主色 | `b` 高光 | `ink` 文字 |
|---|---|---|---|
| 智能扫描(品牌金) | `#D3A24A` | `#E6C078` | `#241703` |
| 清理(青蓝) | `#3C93B0` | `#5AB4CE` | `#03212B` |
| 软件(紫) | `#8E72CE` | (同族更亮) | 深紫墨 |
| 优化(铜橙) | `#B0702E` | `#CE8C44` | `#231402` |
| 分析(橙陶土) | `#C86B49` | (同族更亮) | 深赤墨 |

### 9.4 语义色(独立于主题色)

| 语义 | 色值 | 用法 |
|---|---|---|
| 成功 | `#63BB95` | 完成对钩、健康徽标 |
| 警告 | `#D89A54` / `#E3B34E` | caution 徽标、FDA 未授权脉冲点 |
| 危险 | `#C15A3E`(填充) / `#E0745C`(文字/图标) | 卸载、强制退出、失败项、高 CPU 火焰 |
| 信息 | `#4C8FD8` / 蓝灰 | info 洞察类 |

风险标识必须 **颜色 + 图标 + 文字** 三通道,不可只用颜色。

### 9.5 形状 / 间距 / 动效

- 卡片圆角:统一 **15px**(小徽标 6–9px、大弹窗 18–20px、胶囊/按钮 999px)。
- 卡片:半透明材质(`--surface` 渐变)+ 1px 内描边(`--line`/`--line-strong`)+ 极轻阴影(`--shadow`)。
- 链接:默认 `#D3A24A`,hover `#E6C078` 带下划线。
- 动效:单次反馈 ≤200ms;转场 ≤400ms;页面切换 = 交叉淡入 + 4px 轻位移(`pageIn` 250–280ms);数字滚动补间 300–500ms easeOut;卡片级联 60ms stagger。
- 弹窗层级(z-index):页面内容 20 < 导航 30/40 < 右键菜单 60 < 分析扫描 75 < 危险确认 80 < 进程详情/许可/引导 70/95/96。**全屏弹窗必须是根容器直接子级**(不能嵌在带 `pageIn` 动画的页面容器里,否则 `transform` 残留会生成层叠上下文把弹窗压到导航下面 —— 这是本稿踩过并修正的坑)。

### 9.6 进程详情弹窗三态(状态页)

点击进程行弹出,按进程类型分三种:
- **系统进程**(root/_windowserver 等):不可终止,底部琥珀提示「系统进程,无法终止。」,仅「复制摘要 / 显示」。
- **用户 App**:完整详情(置信度/识别依据/线程数/打开文件/磁盘 I/O/工作目录…),底部「复制摘要 / 显示 / 终止 / 强制退出(危险色)」;终止/强制退出走二次确认弹层。
- **已退出**(点击时进程已不在):极简卡片 + 红字「进程 X 已不在运行。」。
- **持续告警态**(2026-08 新增):进程有 `process_alerts` 记录时,进程树下方插入琥珀告警条「持续高 CPU · 已持续 N 分钟 > 100%」+ `ALERT` 微标签。

## 10. 已预留但本轮未落稿(Phase 5,按需求文档 P4 后置)

以下四项本轮**有意未做**,设计约束先写在这里,免得后续实现者自行发挥:

1. **大文件「新鲜度日期」**:尺寸旁加 mono 日期(如 `2024-06`),超阈值项加「两年未变动」类微标签。**只对不可重建数据显示**(备份、归档、影音)——缓存类**永不显示日期**,它们的年龄不改变结论。此取舍是设计决策,实现时不得扩大化到缓存分组。
2. **历史页结构化撤销**:文件行尾「恢复」+ 会话级「全部恢复」,用**中性色不用危险色**(它是危险操作的逆操作)。两个核心边界态:「废纸篓中已不存在」/「原位置已有同名文件」。依赖 CLI `robot history restore`。
3. **空间趋势 Timeline**:近 30 天磁盘可用空间面积图,复用状态页网络图的视觉语言;数据点 = 每次扫描/清理记录;<2 个数据点时显示「再完成一次扫描即可看到趋势」。**固定 30 天,不做时间范围配置**。
4. **外置卷清理入口**:清理页 idle 态目标切换(默认「启动磁盘」,检测到外置卷时出现),结果页标注卷名;边界态「外置卷已断开连接」。依赖 `robot clean plan --external <path>`。

**同时明确不做**(防走样):菜单栏模式、清理计划提醒、卸载监听、优化任务时长估计、进程表按告警自动重排序、空间趋势时间范围配置。
