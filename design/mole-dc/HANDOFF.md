# Mole for Mac —— 设计稿交接说明(致 Claude Code)

本文件随 `Mole.dc.html` + `support.js` 一起交付。请先读这份,再动代码。

---

## 0. 这是什么 / 不是什么

- **是**:一份**高保真交互设计原型**,用来定稿视觉语言、信息架构、交互流程、动效。所有页面、状态、动画都真实可运行。
- **不是**:生产代码。它跑在一个叫 **DC(Design Component)** 的原型运行时上(`support.js` 就是这个运行时,**不要改它、不要照它的模式写生产代码**)。
- **所有数据都是编造的**(进程、应用、磁盘树、历史、指标)。生产版必须替换成真实的系统 API 调用。见 §5。

开发时的正确姿势:把它当**规格说明书 + 像素级参考**,用你选定的原生技术栈(SwiftUI / Tauri / Electron 等)**重新实现**,而不是把这个 HTML 直接打包。

---

## 1. 架构速览(原型侧)

- 单文件 `Mole.dc.html`:顶部 `<helmet>`(字体/keyframes/body reset,含 `a`/`a:hover` 链接色)→ 模板(`<x-dc>` 内的标记)→ 逻辑类 `class Component extends DCLogic`。
- 渲染模式:逻辑类的 `renderVals()` 返回一个大对象,模板用 `{{ 路径 }}` 取值;`sc-for` / `sc-if` 做循环与条件。
- **样式全部内联**(no CSS class),主题靠 CSS 变量。这是原型运行时的要求,生产版用你自己的样式体系即可,别被这点束缚。
- 状态机核心:`this.state.page`(当前模块)+ 各模块自己的子状态(如 `cleanState: idle/scanning/confirm/executing/done/empty`)。

---

## 2. 设计语言(必须保留的部分)

**气质关键词:精致、克制、可信、专业但不冰冷。** 不要营销式空话("一键加速""深度焕新"),所有文案说清后果("将把 129 项移入废纸篓,共 8.9 GB")。

**字体三分工:**
- 英雄数字(可清理体积、健康分、大读数)→ **Instrument Serif**(衬线,有设计感)
- 单位 / 路径 / 索引 / 英文微标签 / 技术信息 → **JetBrains Mono**(等宽仪器感)
- 中文标题、正文 → **思源宋体 / 思源黑体**(Noto Serif SC / Noto Sans SC)

**主题系统:**
- 三套明暗 LOOK(`LOOKS`):`Ink`(暖墨深色,默认)、`Onyx`(冷墨深色)、`Paper`(暖象牙浅色)。深/浅由设置的"外观"(自动/浅色/深色)驱动。
- 六个模块各一主题色相(`THEMES`),用于该页高亮、强调按钮、图表主色、焦点环:
  - 智能扫描 `#D3A24A` 品牌金 ・ 清理 `#3C93B0` 青蓝 ・ 软件 `#8E72CE` 紫
  - 优化 `#B0702E` 铜橙 ・ 分析 `#C86B49` 橙陶土 ・ 状态 `#4CA07C` 绿(健康语义)
- 切页时背景有一层 <8% 的主题色氛围渐变,400ms 交叉淡入。
- 语义色独立于主题色:成功=绿、警告=琥珀、危险=红。**风险标识必须"颜色+图标+文字"三通道齐全**,不能只靠颜色。

**卡片:** 大圆角(统一 15px)、半透明材质、1px 内描边、极轻阴影。

## 3. 三个信任承诺(产品灵魂,不可删)

任何"动手删用户文件"的地方都必须兑现:
1. **删之前看得见** —— 破坏性操作前展示完整的将删列表 + 总大小,可逐项取消。
2. **删了能找回** —— 一律移入废纸篓(不是永久删),文案强调可恢复。
3. **删过有记录** —— 每次操作写入历史页。

风险三级:`safe`(默认勾选)/ `caution`(琥珀徽标、默认不勾、hover 说明原因)/ `info`(不可勾、洞察卡形式)。白名单命中项灰化 + 盾牌图标。

---

## 4. 焦点环(Focus Ring / 光谱环)——核心动效资产

- 智能扫描 / 清理 / 优化 / 分析扫描 共用**同一个 canvas 引擎**(逻辑类里的 `initOrb()` / `loop()`)。
- 状态机:静息呼吸 → 扫描(刻度均衡器 + 扫描头掠过 + 环心读数上翻)→ 等待确认 → 执行(甜甜圈弧段随进度放空/点亮)→ 完成(收束定格)。
- 颜色自动取当前模块主题色。
- **Reduce Motion**:设置里的"减弱动态效果"开启时,粒子/转场停用、只保留数字补间。生产版必须实现同款降级(并尊重系统 `prefers-reduced-motion`)。
- 动效原则:单次反馈 ≤200ms、转场 ≤400ms、环为环境动画不阻塞点击。

生产实现建议:用 Metal / Canvas / SwiftUI Canvas 复刻,关键是"扫描→结果"的形态连续过渡(环收束成甜甜圈/结论),别做成两个割裂的画面。

---

## 5. ⚠️ 全是假数据 —— 生产必须接真实 API

原型里这些都是写死的 mock,开发时逐一替换:

| 模块 | mock 位置(逻辑类字段) | 真实来源 |
|---|---|---|
| 清理分组/条目 | `CLEAN_GROUPS` | 实际扫描 ~/Library/Caches、日志、浏览器、开发者工具、残留… |
| 已装应用 | `APPS` | `/Applications` + `~/Applications` + bundle 元数据 + 残留路径推断 |
| 更新 | `UPDATES` | App Store / Sparkle / Electron 更新检查 |
| 启动项/服务 | `LOGIN` / `SVC` | LaunchAgents / LaunchDaemons / 登录项 |
| 优化任务 | `OPT_TASKS` | 真实维护命令(部分需管理员 helper) |
| 磁盘树 | `ensureDisk()` 生成 | 真实递归扫盘(需 FDA 权限) |
| 系统指标 | `initStat()` / `statTick()` 随机游走 | IOKit / sysctl / powermetrics 等真实传感器 |
| 进程表 | `_proc` 数组 | 真实进程列表(注意:进程 CPU% 多核可 >100,原型钳到 99) |
| 历史 | `HISTORY` | 本地操作日志持久化 |

**权限**:深度扫描需要 **完全磁盘访问(FDA)**;深度维护/风扇电池养护需要**管理员后台 helper**。Onboarding 第 2/3 步和设置·权限中心已设计好授权引导与状态卡,按那个交互实现真实检测与跳转。

## 6. i18n(重要:原型是临时方案)

- 原型用一个 `TR` 字典(中→英)+ 渲染后遍历 DOM 文本节点替换的 `translateDOM()`。**这是原型 hack,生产别照抄**。
- 但 `TR` 字典本身是一份**很有价值的中英对照术语表**(几百条 UI 文案),生产做正式 i18n(`.strings` / `.xcstrings` / i18next 等)时,直接拿它当词表起点。
- 目前支持中/英两语,语言在设置·通用切换;需可扩展更多语言。
- 数字/日期要按 locale 格式化(原型里扫描时间戳 `M月D日` → 英文 `Jul D` 已示范)。

## 7. 页面清单(9 页 + 菜单)

智能扫描(首页)・清理(4 状态)・软件(卸载/更新/启动项 三 tab + 三段式移除)・优化(清单→执行→完成 + 管理员授权层)・分析(Treemap + 目录联动 + 下钻转场)・状态(8 指标卡 + 进程表 + 结束进程确认)・历史・设置(通用/白名单/权限/许可/高级/关于)・Onboarding(3 步)・系统菜单(Mole 徽标下拉 + 许可证弹窗)。

**边界状态都已设计**:空态、加载骨架、错误卡片(清理失败项可展开)、无 FDA 横幅、数据断连重连、零结果("你的 Mac 很干净"愉悦态)。生产别只实现理想态。

---

## 8. 验收自检(沿用设计基线)

- 任一屏 5 秒内看懂"现在发生了什么、我能做什么"。
- 所有破坏性操作前可见完整将删列表 + 总大小。
- 风险信息 颜色+图标+文字 三通道齐全。
- 深浅双模式对比度达标(WCAG AA)。
- Reduce Motion 有完整降级。
- 窗口 980→1600pt 拉伸不破版(最小 980×640,默认 1200×760)。
- 气质:像专业工具,不像"清理垃圾软件"。

有拿不准的交互/视觉细节,以 `Mole.dc.html` 实际运行效果为准。
