# Mole for Mac —— 项目上下文与来龙去脉

> 本文件是给"接手这个项目的下一轮设计工作"看的备忘,记录产品是什么、设计一路是怎么定下来的、现在做到哪、哪些是待办。开发交接看 `HANDOFF.md`。

---

## 1. 项目是什么

**Mole for Mac** —— 一款原生 macOS 系统维护应用的**高保真交互设计原型**。能力:系统垃圾清理、已装软件管理与卸载、系统优化维护、磁盘空间可视化分析、系统健康状态监控。

- 交付形态:单文件 Design Component `Mole.dc.html`(+ 原型运行时 `support.js`)。
- 气质关键词:**精致、克制、可信、专业但不冰冷**。对标 CleanMyMac / Raycast / Linear 的完成度,但视觉**完全原创**。
- 三个信任承诺(产品灵魂,任何破坏性操作都要兑现):**删之前看得见 · 删了能找回(进废纸篓)· 删过有记录**。
- 文案红线:不许"一键加速""深度焕新"这类营销空话,一律说清后果(如"将把 129 项移入废纸篓,共 8.9 GB")。

## 2. 设计一路是怎么定下来的(关键决策 + 缘由)

设计方向是在和用户多轮往复中逐步收敛的,理解这些"为什么"比结论更重要:

1. **抛弃默认设计系统。** 项目原本绑定 Spectrum 2,但用户明确授权"美观度优先,可不用默认系统,自己设计一套"。Spectrum 2 只作尺寸/间距参考。
2. **焦点视觉体演进了三代:**
   - 一代:旋转粒子球 → 用户嫌单调、扫描完还留个小球没意义。
   - 二代:"光谱环 / Spectrum Ring"——刻度均衡器扫描 → 收束成甜甜圈结论。**这是定稿方向**(form follows data)。
   - 三代:配色/材质升级(见下)。
3. **art direction 定稿 = "Instrument"(精密仪器)。** 用户要"能获设计大奖、眼前一亮"的效果,于是从"冷黑+霓虹"(太 gamer-RGB)转向**暖墨(warm ink)+ 金**、胶片颗粒、编辑感排版。
4. **字体三分工(定稿,用户亲自拍板):**
   - 英雄数字 → **Instrument Serif**(用户特别喜欢的衬线数字,一度被换成 mono 又应用户要求换回)。
   - 单位/路径/PID/索引/英文微标签/技术信息 → **JetBrains Mono**(用户指定英文用它)。
   - 中文标题 → **思源宋体 Noto Serif SC**;中文正文 → **思源黑体 Noto Sans SC**。
   - 张力点:"西文等宽机械 × 中文宋体人文"。
5. **六模块各一主题色(用户要求相邻可辨):** 智能扫描金 `#D3A24A`・清理青蓝 `#3C93B0`・软件紫 `#8E72CE`・优化铜橙 `#B0702E`・分析橙陶土 `#C86B49`・状态绿 `#4CA07C`。
   - 曾经"清理"漂成青绿和"状态"绿撞车、"优化"和"智能扫描"都偏金 → 已按用户要求拉开(清理改冷青蓝、优化改深铜橙)。
6. **三套明暗 LOOK:** Ink(暖墨,默认深)/ Onyx(冷墨深)/ Paper(暖象牙浅)。设置·通用「外观」= 自动/浅色/深色。
7. **初始态统一:** 清理/优化/分析三页初始态统一为"标签 + 宋体标题 + 三胶囊 chips + 渐变按钮 + 副行",光谱环只在扫描/执行时出现;智能扫描页保留动态环作品牌首页(有意的层级区分)。
8. **动画一律用光谱环**,不照搬用户给的参考图(行星/吉祥物)。参考图只借鉴信息架构和呈现节奏。

## 3. 现在做到哪(全部已完成并验证)

**九个页面 + 系统菜单 + 各类弹窗,全部接通、可交互:**

- **智能扫描**(首页):动态光谱环 + 待扫描→扫描→2×2 结论矩阵(环收束成甜甜圈)。
- **清理**:六态(待扫描/扫描/结果确认/执行/完成/零结果愉悦态)。结果确认含 16 类分组三态勾选 + 右侧明细 + 风险三通道(safe/caution/info)+ 已保护白名单 + 洞察卡;三子 tab(快速清理/项目产物/安装包);完成态含**失败项可展开错误卡片**。
- **软件**:三 tab(卸载/更新/启动项)。卸载含搜索/排序/筛选、行内展开残留清单、勾选联动、底部批量栏、**三段式移除**(危险确认→光谱环执行→完成小结);加载骨架屏。
- **优化**:静态初始→(自定义清单)→管理员授权弹层→电影感执行态(常驻光谱环+滚动任务日志)→完成态。
- **分析**:入口说明页→全屏光谱环扫描→Squarified Treemap + 目录侧栏双联动 + 面包屑 + 下钻扫描 loading + 右键菜单(聚合块已抑制无效菜单)+ 移废纸篓二次确认;记忆上次扫描;刷新/⌘R 重扫。
- **状态**:进入自动加载→8 张指标卡(带 icon + 丰富底部信息)+ 可滚动进程表(~27 条)+ **进程详情弹窗三态**(系统进程不可终止/用户 App 完整详情/已退出极简卡)+ 结束进程二次确认 + 刷新率切换 + 断连重连降级态。
- **历史**:会话时间线 + 逐项展开 + 空态。
- **设置**:通用/白名单/权限中心/**许可(付费买断¥298 / 订阅¥128,含激活/已激活态)**/高级/关于。
- **Onboarding**:三步(品牌三承诺→FDA 实时检测→可选 helper),水平滑动转场。
- **系统菜单**:Mole 徽标下拉 + 许可证弹窗。

**横切能力:** 深浅双模式全量 + 中英双语(i18n)+ Reduce Motion 全套降级 + 七模块主题联动。

## 4. i18n 现状(重要)

- 机制:`TR` 中英字典 + **渲染后 DOM 遍历替换** `translateDOM()`(原型 hack,生产别照抄,但字典可当术语表起点)。renderVals 拼装的数据串走 `tr()`。
- 覆盖:全应用英文态 CJK 扫描已清零,中英双向切换无残留。日期/数字按 locale 格式化。
- 语言在设置·通用切换(自动/中文/English),可扩展更多语言。

---

## 5. 踩过的坑(别重犯)

- **全屏弹窗必须是根容器直接子级**,不能嵌在带 `pageIn`(`translateY(0)`)动画的页面容器里 —— transform 残留会生成层叠上下文,把弹窗压到导航下面。进程详情弹窗、许可、Onboarding 都已移到根级。
- **切页副作用用 `componentDidUpdate` 驱动,别用 rAF** —— 后台标签 rAF 被节流,会导致主题色/高亮不切换。
- **光谱环在浅色模式**要改用正常混合模式(非 `lighter` 叠加)+ 深棕刻度加权,否则在亮底上看不见。
- 多实例热重载会让旧 loop 读旧 state/失效 ref,产生"环空白/数字冻结"假象 —— 硬刷新即恢复,已加"只跑最新实例"守卫。

## 6. 全是假数据

原型里 `CLEAN_GROUPS / APPS / UPDATES / LOGIN / SVC / OPT_TASKS / ensureDisk() / initStat() / _proc / HISTORY` 全是编造的 mock。生产要逐一替换成真实系统 API(详见 `HANDOFF.md` §5 的对照表)。深度扫描需 FDA,深度维护需管理员 helper。
