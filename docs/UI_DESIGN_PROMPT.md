# Mole for Mac — UI 设计任务提示词

> 用途：本文档是提供给 Claude Design（或其他 AI/人类设计师）的完整 UI 设计提示词。
> 配套：功能与技术规格见 `docs/MAC_APP_DESIGN.md`（本提示词的页面/模块/交互均与其对应）。
> 使用方式：整篇复制给设计工具即可，无需额外上下文。

---

## 一、项目背景与设计目标

你要为一款名为 **Mole** 的原生 macOS 系统维护应用设计完整 UI。它的能力包括：系统垃圾清理、已装软件管理与卸载、系统优化维护、磁盘空间可视化分析、系统健康状态监控。

产品气质关键词：**精致、克制、可信、专业但不冰冷**。它是一个"动手删用户文件"的工具，所以设计必须传递三个承诺：**删之前看得见（可预览）、删了能找回（进废纸篓）、删过有记录（有历史）**。任何界面都不允许出现"一键加速""深度焕新"这类营销式空话，所有文案都要说清楚具体后果（如"将把 129 项移入废纸篓，共 8.9 GB"）。

设计目标排序：**美观精致 > 信息直观 > 操作效率**。我们要求达到 CleanMyMac / Raycast / Linear 这一档的视觉完成度，但视觉语言必须原创，不得模仿任何现有产品的具体样式。

## 二、整体框架与设计系统

### 2.1 窗口与导航

- 单窗口应用，默认 1200×760，最小 980×640，支持自由拉伸，所有页面需给出响应式行为说明。
- 隐藏系统标题栏（内容延伸到窗口顶部，保留左上角红黄绿灯）。
- **顶部居中胶囊形分段导航**，包含六个入口：`智能扫描 · 清理 · 软件 · 优化 · 分析 · 状态`。胶囊左端是 Mole 圆形徽标（鼹鼠图形，点击回智能扫描页）；胶囊右端外侧放两个弱化的图标按钮：历史（时钟图标）、设置（齿轮图标）。
- 选中的导航项为实心高亮胶囊，切换页面时高亮块做平滑的位移过渡（spring 动画，~250ms）。

### 2.2 色彩与主题

- **深色模式优先设计**，同时交付完整浅色模式。深色基底建议极深的冷灰蓝（非纯黑），营造纵深感。
- **每个模块一个主题色相**，用于该页的焦点视觉、强调按钮、图表主色。建议方向（可微调）：清理=青蓝、软件=紫、优化=琥珀金、分析=橙棕、状态=多色仪表但以绿为健康基调、智能扫描=品牌主色。页面切换时背景带一层极淡的主题色氛围渐变（radial gradient，透明度 <8%），过渡 400ms 交叉淡入。
- 语义色：成功=绿、警告=琥珀、危险=红、信息=蓝灰。风险标识不允许只靠颜色，必须同时有图标 + 文字。
- 对比度满足 WCAG AA。

### 2.3 排版与数字

- 系统字体 SF Pro；**关键数字用大号 SF Pro Rounded 或等宽数字**（如"可清理 8.92 GB"中数字部分 44–56pt），说明文字 13pt 退后处理。
- 所有动态数字变化必须做**滚动补间动画**（数字上翻/滚轮效果，不允许生硬跳变）。
- 文件路径类文本：中间截断，hover 显示完整路径 tooltip。

### 2.3b 国际化（i18n）设计约束

- 产品双语发布（简体中文 + English），后续可能增加语言。**所有含文字的组件必须按"英文比中文长 30–60%"做弹性设计**：按钮、徽标、表头、tab 一律不定死宽度，给出文字超长时的行为（换行/截断/缩字号，逐组件注明）。
- 交付时关键页面（智能扫描、清理确认、设置）需提供**中英双版本**各一份，验证布局韧性。
- 图片/插画中不得内嵌文字（空状态插画等一律图形化表意，文字用可本地化的文本层叠加）。
- 数字与单位格式跟随系统区域（如 8.92 GB / 8,92 GB），温度单位受设置控制（°C/°F），设计标注中注明这些位置是格式化变量而非固定文案。

### 2.4 材质与组件基调

- 卡片：大圆角（12–16pt）、半透明深色材质（类 macOS vibrancy），1px 内描边提亮上边缘，阴影极轻。
- 通用组件需成体系设计并单独出组件页：卡片、统计徽标、分组勾选列表、滚动结果日志、风险徽标（safe/caution/info 三级）、光谱环 + 甜甜圈占比图（焦点视觉，见 §2.5）、结论卡片（含编号角标）、迷你趋势图 sparkline、空状态插画、权限提示横幅、主按钮/次按钮/危险按钮。

### 2.5 焦点视觉（全产品最重要的视觉资产）：光谱环（Spectrum Ring）

清理、优化、智能扫描页的中央焦点视觉是一个 **"光谱环"（Spectrum Ring）**——一枚精密仪表般的圆环（直径约 340–420pt），核心设计原则是**形态跟随数据**：它不是一个固定动画背景，而是随扫描状态实时改变形态，最终**变成结果本身**。三个形态：

- **静息** = 一圈细密的径向刻度环，缓慢呼吸，像一台待命的精密仪器（不是点云、不是粒子球）。
- **扫描中** = 一个"扫描头"沿环行进，经过处刻度如波浪般跳动（一台环形均衡器，对扫到的内容做出反应）；总量在环心像仪表一样滚动上翻；发现大项时向外发散涟漪；扫过的进度以双色渐变弧记录。
- **完成** = 环**就地重组为甜甜圈占比图**——同一个圆按各类可清理内容的真实体积重新分段为彩色弧段，总量留在环心。它不消失，而是作为一份**有意义的图例**保留，颜色与下方结果卡片一一对应。

硬性要求：

- **数据驱动，不是装饰**：扫描时环上刻度的跳动幅度 ∝ 实时发现量；完成时每段弧的角度 ∝ 该类内容的真实占比。扫出什么，画面就长什么样。
- **每个状态都有职责**：**没有多余的残留小球/漂浮轨道**（旧粒子球方案扫描后留一个缓慢转动的小球是纯装饰，已废弃）。完成态的甜甜圈本身就是结果与图例。
- **可交互**：完成态 hover 某弧段显示该类的名称与大小 tooltip，点击弧段跳转到对应处理页。
- **禁止**使用写实星球/地球素材，禁止退回通用"能量球/粒子球"形态（行业陈词滥调）。
- 四个模块主题色仍生效：环/甜甜圈用当前模块的双色品牌渐变着色。
- 完整的四状态动效系统见第四节。

## 三、逐页面设计要求

### 页面 1：智能扫描（默认首页）

**功能**：一键聚合体检，汇总"可清理空间、卸载残留、安装包、大文件洞察"。

- **初始态**：中央光谱环处于静息刻度环状态，环心显示 `READY`，环下方一行字距拉开的等宽小标签 `SYSTEM INTEGRITY CHECK`；再下方大号主按钮"开始智能扫描"（琥珀实心胶囊，带放大镜图标），按钮下一行小字说明扫描内容与耗时（如"聚合体检约需 30 秒 · 缓存、卸载残留、安装包与大文件洞察"）。页面**底部一行三个弱化信息位**：`LAST SCAN / LAST FREED / DISK FREE`（英文字距标签 + 数值），首次使用时显示占位破折号。
- **扫描态**：光谱环进入环形均衡器动效——扫描头沿环行进、刻度波动、进度以双色渐变弧记录；**环心是仪表读数**：小标签 `RECLAIMABLE` + 大数字实时上翻"10.84 GB"（数字白、单位琥珀）。环下方一行当前扫描路径（前缀琥珀圆点 + 灰色单行，中间截断，高频更新时淡入淡出而非闪跳）。底部提供描边"停止扫描"胶囊按钮。
- **结果态**：光谱环就地重组为**甜甜圈占比图**（各弧段颜色对应下方卡片），环心显示总量"13.4 GB"；上方标题"体检完成"，下方字距标签副标题 `BROKEN DOWN BY TYPE · N INSIGHT FOUND`。再下方是**单行四张结论卡**（不是 2×2，避免窄窗溢出）：可安全清理（X GB，青绿 + "安全"徽标）、卸载残留（N 项，紫）、安装包（M 个，金）、空间洞察（最大目录…，橙 + "洞察"徽标）。每张卡：左上角 tinted 圆角图标、右上角编号（01–04）、大数字、标签、一句结论描述、底部彩色动作链接（"去处理 →" / "去分析 →"）。卡片入场做 60ms 间隔的级联浮现。底部居中"重新扫描"描边按钮。
- 需设计：FDA（完全磁盘访问）未授权时顶部的常驻提示横幅——琥珀圆点 + 加粗标题"完全磁盘访问未授予" + 说明"部分系统位置将被跳过，授权后可扫描全部缓存与残留" + 右侧"前往授权"按钮 + × 可关闭。

### 页面 2：清理

**功能**：深度清理，三个子 tab：`快速清理 / 项目产物 / 安装包`（页内二级小胶囊切换）。

四个状态：

1. **待扫描**：光谱环静息 + "开始扫描"按钮 + 三个承诺的图标短句（可预览/进废纸篓/有记录）。
2. **扫描中**：同智能扫描的动效语言，但用清理页主题色。
3. **结果确认（本页核心，重点设计）**：
   - 布局：左侧分组列表（约 260pt 宽）+ 右侧条目明细表 + 顶部汇总栏。
   - 顶部汇总栏：左侧"已选 X.XX GB / 共 Y.YY GB"（大数字，勾选变化时滚动补间），右侧主行动按钮"清理已选项"。
   - 左侧分组：16 类清理分组（用户缓存、应用缓存、浏览器、开发者工具、应用残留、设备备份等），每行 = 组名 + 条数 + 总大小 + 三态勾选框（全选/半选/不选），选中组高亮。
   - 右侧明细表：条目 = 勾选框、名称、说明小字（如"应用重启后自动重建"）、大小、风险徽标。**风险三级**：safe 默认勾选；caution 琥珀徽标、默认不勾选、hover 展示原因；info 类（大文件洞察等）不可勾选，呈现为列表顶部的"洞察卡片"，只有"去分析页查看"动作。
   - "已保护"分组：白名单命中项灰化 + 盾牌图标 + "管理白名单"入口。
4. **执行中 → 完成**：光谱环进入执行态（甜甜圈弧段随各类清理进度放空回缩，环心倒数为"已释放 X.XX GB"，见 §4.1）；下方是**滚动结果日志区**（半透明容器，高约 200pt）：逐项滚入，成功=青色对钩、跳过=灰色、失败=红色可展开原因；当前项之外的历史行降低透明度形成纵深。完成后过渡到小结卡：大数字"已释放 X.XX GB"、成功/跳过/失败计数、"全部已移入废纸篓，可随时恢复" + "查看历史"链接 + "完成"按钮。

### 页面 3：软件

**功能**：软件治理。页内左上角**三个子 tab：卸载 / 更新 / 启动项**；右上角共用工具栏（排序：名称/大小/最近使用/安装日期，各带升降箭头；刷新；搜索；部分 tab 有筛选下拉）。三个 tab 各自的设计：

#### tab A · 卸载（重点设计）

- 列表头：`已安装应用 N 个 · X GB`。列表行：应用图标、名称、版本、大小（右对齐等宽）、最近使用（区分"活跃"/"N 个月前 打开过"）。**受保护应用**显示盾牌徽标，卸载不可用，hover 说明原因。
- **行内展开选择（核心交互，参考图）**：勾选某应用后该行高亮 + 左侧出现强调条 + 行内展开一条摘要 `N 个已选 · 493.8 MB + 12.9 MB 需复核`——高置信残留自动计入，低置信残留单列标 **"需复核"**（琥珀，默认不勾）。行右侧勾选框 + 展开箭头看完整残留清单（按 Application Support / Caches / Preferences / 启动项分组，逐项路径与大小）。
- **底部批量操作栏**：`<App名> · N 个 App · X MB` + "取消全选" + 右侧白色主按钮"移除 N 项"。多选累加。执行 = 全部移入废纸篓（危险确认）。
- **残留清理**：已卸载应用的孤儿文件按"疑似所属应用"分组（灰色虚线幽灵图标表示应用已不存在）。

#### tab B · 更新

- 列表头：`可在 Mole 内更新 N 个` + 右侧"全部更新"。工具栏加**来源筛选下拉**（全部 / App Store / Homebrew / Sparkle / Electron）。
- 行：图标、名称、**来源徽标**（App Store / Homebrew / Sparkle / Electron，可点 `>` 看详情）、`旧版本 → 新版本`（新版本橙色高亮）、右侧"忽略更新"文字链接 + "更新"实心按钮（橙）。
- 设计约束提示（给设计师）：这是"检测 + 一键更新"列表，不是进度轰炸；更新中的行显示行内进度条 + "更新中…"，完成后行淡出。无更新时的空态"全部都是最新的"要设计得令人愉悦。

#### tab C · 启动项

- 工具栏加**筛选下拉**（已开启 / 全部 / 孤儿）。分两组：`登录项 N 个`（用户级 Login Items）与 `后台服务 M 个`（LaunchDaemon / LaunchAgent）。
- 行：图标（无图标的服务用齿轮占位）、名称、副行 `类型 · 状态 · 标签(bundle helper id / plist label)`、右侧**开关**。hover 行显示"在 Finder 中显示"文件夹图标。
- **系统项与 `com.apple.*`**：开关禁用（灰）并 hover 说明"系统项不可更改"。**操作是禁用/启用而非删除**（可恢复）。daemon 开关切换时若需管理员权限，给一次性授权说明。

三个 tab 均需出图；卸载 tab 额外出"含选中行内展开 + 底部批量栏"的状态帧。

### 页面 4：优化

**功能**：系统维护任务清单，先解释后执行。

- **清单态**：任务卡片按四个分区排列：日常维护 / 修复小毛病 / 深度维护 / 体检报告（只读审计类）。每张卡：图标、任务名、一句话说明、预估时长、需要管理员权限时的钥匙徽标；卡片可展开"会做什么"详情（具体命令级描述）。顶部：推荐组合快捷选择（全部日常/全部修复）+ "执行已选 N 项"主按钮。
- **执行态（重点设计动画）**：页面转为专注模式——光谱环的"养护光波"变体（见 §4.1，环均分为任务段、逐段点亮，优化页主题色）+ 标题"正在优化系统" + 环心进度"4/23"；下方任务清单流：已完成项打钩收拢、当前项高亮呼吸、待执行项半透明。任务逐个完成时对钩要有绘制动画（stroke 动画 ~300ms）。
- **完成态**：结果摘要，每个任务给具体结果文案（如"DNS 缓存已刷新""清理了 14 个失效登录项"）；skipped 项如实展示原因（如"需要管理员权限"）。
- 需设计：管理员权限任务的授权引导弹层（说明 helper 是什么、只做什么）。

### 页面 5：分析

**功能**：磁盘空间可视化，Treemap + 目录列表双联动、可无限下钻。这是"像 CleanMyMac/DaisyDisk 那样"的核心页，重点设计。

**布局**：左栏（约 300pt）+ 主区 Treemap + 顶部导航栏。

- **左栏**：
  - 顶部：当前目录的圆形图标/头像 + 汇总"N 项, X GB"。
  - 目录条目列表（大小降序）：文件夹/文件图标、名称、大小、可选的水平占比条；条目尾部 `>` 箭头表示可进入；**可清理目录用专属图标 + 主题色**（如开发缓存 `.cache` 用工具图标）。
  - 交互：**单击条目 = 下钻进入**（与点击 treemap 对应块等效）；**右键菜单 = 在 Finder 中打开 / 移到废纸篓**（需设计该右键菜单浮层，见参考图）。列表可滚动展示当前层全部真实子项。
- **主区 Treemap**（Squarified）：
  - 块内容：文件夹图标 + 名称 + 大小；块太小放不下时仅 hover tooltip。
  - **小项聚合块（务必设计）**：占比过小的众多尾部项**合并为一个聚合块**，块内用网格图标 + "N 项 · X GB"（中性灰着色，明显区别于真实目录块——参考图的"186 项 54.05 GB""49 项 960.8 MB"）。**点击聚合块进入"其他 N 项"子视图**并可继续下钻，不是死块。
  - 着色：真实目录块按大小走暖色系深浅（大块更亮）；个别需注意的块（如超大 Downloads）可用偏红色调；cleanable 块用主题强调色；聚合块中性灰。
  - hover 提亮 + 阴影抬升 + tooltip（完整路径/大小/最后访问时间）；**单击下钻**（未扫过的目录先触发扫描，块上显示 loading，扫完进入并更新面包屑）——**需设计下钻转场**：被点击块放大铺满 → 内部子块级联浮现，~350ms；返回为逆过程。
  - 右键菜单：在 Finder 中打开 / 移到废纸篓 / 添加到白名单。保护路径的块：删除项禁用并说明。
- **顶部导航栏**：
  - **面包屑**（`🏠 根目录 > jiangding > … > Application Support > Google > Chrome`）：可点击任意层级跳转；**路径过深时中间层折叠为 `…`**，需设计 `…` 展开的下拉。首段 home 图标固定为"根目录"。
  - 右侧状态区：`当前 X GB · 磁盘 已用/总量 GB`；**扫描中显示旋转进度指示器，完成后显示刷新按钮**（重扫当前目录）——两种状态都要出图。
- 扫描进行中的骨架态：块从模糊占位逐渐清晰、大小渐进收敛。

## 四、动画系统（最高优先级需求，请单独成章交付）

我们要求清理/优化过程的动画**流畅、酷炫、有记忆点**，这是产品体验的灵魂。请为以下动效逐一给出：视觉描述、时长、缓动曲线、触发条件，并保证整套动效语言统一。

### 4.1 光谱环（Spectrum Ring）状态机

贯穿智能扫描/清理/优化页的核心动效资产。核心原则：**形态跟随数据，每个状态都有职责，没有装饰性残留元素**。五个状态及状态间过渡：

1. **静息（Idle）**：一圈细密径向刻度环，整体缓慢呼吸（振幅 ±1.5%，周期 5–6s），刻度长度有极轻微的随机起伏，像一台待命的精密仪器；环心 `READY` + 中央一枚极小的琥珀光点。安静、克制、有精度感。
2. **扫描中（Scanning）**：一个**扫描头**沿环顺时针行进（转速与扫描进度轻微正相关），行进轨迹留下一段**双色渐变进度弧**（品牌双色）；扫描头经过处的刻度如**环形均衡器**般被激起、随后回落，形成一圈流动的波形；环心是仪表读数（`RECLAIMABLE` + 大数字上翻），数字上翻与发现事件联动；**发现大体积项**时从该角度向外**发散一圈涟漪** + 环轻微膨胀脉冲一次。
3. **结果重组（Resolve，最关键的转场）**：扫描头回到起点闭合 → 均衡器刻度**收拢并重排**为若干**比例弧段**（每段角度 ∝ 该类真实占比，颜色对应结果卡片）→ 环心数字从"已发现"平滑过渡为"总量"。整段 ~800ms，是"环变成结果"的高光时刻。
4. **完成/图例态（Legend）**：甜甜圈占比图定格并保留，作为与下方卡片色彩联动的**活图例**；hover 弧段提亮 + tooltip，点击弧段跳转对应处理页。不做任何多余的漂浮/自转动画。
5. **执行态（清理页专属，Execute）**：进入清理执行时，甜甜圈的对应弧段随每类的清理进度**从满逐渐"放空"回缩**（弧长按已释放比例缩短），环心数字从"待清理"倒数为"已释放 X.XX GB"；全部完成时环做一次收束脉冲 + 一道亮环扩散，大数字弹性定格。整段完成动效 ~1.2s，有仪式感但不拖沓。

**优化页变体**：优化不是"清理占比"而是"逐项养护"，光谱环复用但语义调整——环被均分为 N 段（N = 待执行任务数），每完成一个任务点亮/填充一段，环心显示"4/23"进度；一道**养护光波**沿环随任务推进扫过。不做甜甜圈占比与放空回缩。

### 4.2 其他关键动效清单

- 数字滚动补间（所有动态数值，300–500ms，easeOut）。
- 结果日志逐行滚入（新行从下方 8pt 淡入上移，120ms）。
- 卡片级联入场（60ms stagger，浮起 + 淡入）。
- 导航胶囊高亮位移（spring）。
- Treemap 下钻/回退转场（§页面5）。
- 任务对钩 stroke 绘制动画。
- 页面切换：内容区交叉淡入 + 4pt 轻微位移，250ms，禁止大幅滑动。
- 状态图表数据点推入动画。
- 危险操作按钮按下时的确认微交互（如按住 0.4s 填充确认，或二次确认弹层，给出你的方案）。

### 4.3 动效原则

- 所有动效必须服务信息传达（进度、因果、层级），禁止纯装饰性长动画阻塞操作。
- 单次交互反馈 ≤200ms；转场 ≤400ms；光谱环为环境动画不阻塞任何点击。
- 需给出"减弱动态效果"（Reduce Motion）开启时的全套降级方案（扫描头行进/刻度均衡器/涟漪/放空回缩停用；扫描态改为静态进度弧 + 环心数字补间；结果重组转场改为甜甜圈直接交叉淡入；刻度呼吸停用；保留数字滚动补间）。
