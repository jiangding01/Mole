# Mole for Mac — UI 设计任务提示词

> 用途：本文档是提供给 Claude Design（或其他 AI/人类设计师）的完整 UI 设计提示词。
> 配套：功能与技术规格见 `docs/MAC_APP_DESIGN.md`（本提示词的页面/模块/交互均与其对应）。
> 使用方式：整篇复制给设计工具即可，无需额外上下文。

---

## 一、项目背景与设计目标

你要为一款名为 **Mole** 的原生 macOS 系统维护应用设计完整 UI。它的能力包括：系统垃圾清理、已装软件管理与卸载、系统优化维护、磁盘空间可视化分析、系统健康状态监控。

产品气质关键词：**精致、克制、可信、专业但不冰冷**。它是一个"动手删用户文件"的工具，所以设计必须传递三个承诺：**删之前看得见（可预览）、删了能找回（进废纸篓）、删过有记录（有历史）**。任何界面都不允许出现"一键加速""深度焕新"这类营销式空话，所有文案都要说清楚具体后果（如"将把 129 项移入废纸篓，共 8.9 GB"）。

设计目标排序：**美观精致 > 信息直观 > 操作效率**。我们要求达到 CleanMyMac / Raycast / Linear 这一档的视觉完成度，但视觉语言必须原创，不得模仿任何现有产品的具体样式。

## 二、整体框架与设计系统

### 2.1 窗口与导航

- 单窗口应用，默认 1200×760，最小 980×640，支持自由拉伸，所有页面需给出响应式行为说明。
- 隐藏系统标题栏（内容延伸到窗口顶部，保留左上角红黄绿灯）。
- **顶部居中胶囊形分段导航**，包含六个入口：`智能扫描 · 清理 · 软件 · 优化 · 分析 · 状态`。胶囊左端是 Mole 圆形徽标（鼹鼠图形，点击回智能扫描页）；胶囊右端外侧放两个弱化的图标按钮：历史（时钟图标）、设置（齿轮图标）。
- 选中的导航项为实心高亮胶囊，切换页面时高亮块做平滑的位移过渡（spring 动画，~250ms）。

### 2.2 色彩与主题

- **深色模式优先设计**，同时交付完整浅色模式。深色基底建议极深的冷灰蓝（非纯黑），营造纵深感。
- **每个模块一个主题色相**，用于该页的焦点视觉、强调按钮、图表主色。建议方向（可微调）：清理=青蓝、软件=紫、优化=琥珀金、分析=橙棕、状态=多色仪表但以绿为健康基调、智能扫描=品牌主色。页面切换时背景带一层极淡的主题色氛围渐变（radial gradient，透明度 <8%），过渡 400ms 交叉淡入。
- 语义色：成功=绿、警告=琥珀、危险=红、信息=蓝灰。风险标识不允许只靠颜色，必须同时有图标 + 文字。
- 对比度满足 WCAG AA。

### 2.3 排版与数字

- 系统字体 SF Pro；**关键数字用大号 SF Pro Rounded 或等宽数字**（如"可清理 8.92 GB"中数字部分 44–56pt），说明文字 13pt 退后处理。
- 所有动态数字变化必须做**滚动补间动画**（数字上翻/滚轮效果，不允许生硬跳变）。
- 文件路径类文本：中间截断，hover 显示完整路径 tooltip。
- 中文为主语言，需同时考虑英文文案的布局适配（英文通常更长）。

### 2.4 材质与组件基调

- 卡片：大圆角（12–16pt）、半透明深色材质（类 macOS vibrancy），1px 内描边提亮上边缘，阴影极轻。
- 通用组件需成体系设计并单独出组件页：卡片、统计徽标、分组勾选列表、滚动结果日志、风险徽标（safe/caution/info 三级）、进度球体、迷你趋势图 sparkline、空状态插画、权限提示横幅、主按钮/次按钮/危险按钮。

### 2.5 焦点视觉（全产品最重要的视觉资产）

清理、优化、智能扫描页的中央都有一个 **"焦点视觉体"（Focus Orb）**——一个程序化生成的抽象几何球体/粒子体（约 280–340pt），承载扫描与执行的全部状态表达。**不要使用写实星球/地球素材**，要原创的抽象形态，例如：由数千粒子构成的球状云、流动的等高线球、呼吸的多层光环。要求为它设计完整的状态动效系统（见第四节）。

## 三、逐页面设计要求

### 页面 1：智能扫描（默认首页）

**功能**：一键聚合体检，汇总"可清理空间、卸载残留、安装包、大文件洞察"。

- **初始态**：中央焦点视觉体处于静息呼吸状态，下方一个大号主按钮"开始智能扫描"，按钮下一行小字说明扫描内容与耗时预期。页面底部一行三个弱化信息位：上次扫描时间、上次释放空间、磁盘剩余空间。
- **扫描态**：焦点视觉体进入扫描动效；球体下方两行信息——第一行大数字实时上翻"已发现 X.XX GB"，第二行当前扫描路径（灰色单行，中间截断，高频更新时做淡入淡出而非闪跳）。右上角提供"停止"文字按钮。
- **结果态**：焦点视觉体收束定格，页面过渡为**结论卡片矩阵**（2×2）：可安全清理（X GB，青蓝）、卸载残留（N 项，紫）、安装包（M 个，金）、空间洞察（最大目录是…，橙）。每张卡片：图标、大数字、一句结论、"去处理 →"。卡片入场做 60ms 间隔的级联浮现。
- 需设计：FDA（完全磁盘访问）未授权时顶部的常驻提示横幅样式。

### 页面 2：清理

**功能**：深度清理，三个子 tab：`快速清理 / 项目产物 / 安装包`（页内二级小胶囊切换）。

四个状态：

1. **待扫描**：焦点视觉体静息 + "开始扫描"按钮 + 三个承诺的图标短句（可预览/进废纸篓/有记录）。
2. **扫描中**：同智能扫描的动效语言，但用清理页主题色。
3. **结果确认（本页核心，重点设计）**：
   - 布局：左侧分组列表（约 260pt 宽）+ 右侧条目明细表 + 顶部汇总栏。
   - 顶部汇总栏：左侧"已选 X.XX GB / 共 Y.YY GB"（大数字，勾选变化时滚动补间），右侧主行动按钮"清理已选项"。
   - 左侧分组：16 类清理分组（用户缓存、应用缓存、浏览器、开发者工具、应用残留、设备备份等），每行 = 组名 + 条数 + 总大小 + 三态勾选框（全选/半选/不选），选中组高亮。
   - 右侧明细表：条目 = 勾选框、名称、说明小字（如"应用重启后自动重建"）、大小、风险徽标。**风险三级**：safe 默认勾选；caution 琥珀徽标、默认不勾选、hover 展示原因；info 类（大文件洞察等）不可勾选，呈现为列表顶部的"洞察卡片"，只有"去分析页查看"动作。
   - "已保护"分组：白名单命中项灰化 + 盾牌图标 + "管理白名单"入口。
4. **执行中 → 完成**：焦点视觉体进入执行动效；下方是**滚动结果日志区**（半透明容器，高约 200pt）：逐项滚入，成功=青色对钩、跳过=灰色、失败=红色可展开原因；当前项之外的历史行降低透明度形成纵深。完成后过渡到小结卡：大数字"已释放 X.XX GB"、成功/跳过/失败计数、"全部已移入废纸篓，可随时恢复" + "查看历史"链接 + "完成"按钮。

### 页面 3：软件

**功能**：已装应用管理与安全卸载。

- **主列表**：工具栏（搜索框、排序：大小/名称/最近使用、筛选 chips：全部/大于1GB/180天未用/Homebrew 安装、列表-网格视图切换）。列表行：应用图标（真实图标位）、名称、版本、大小（右对齐等宽）、最近使用时间、来源小徽标（App Store/brew/手动）。**受保护应用**（浏览器、系统关键组件等）显示盾牌徽标，卸载不可用，hover 说明原因。
- **详情抽屉**：点击行从右侧滑出（~380pt）：大图标、名称版本、bundle id（可复制）、占用构成的横向堆叠条（应用本体 vs 数据）、操作按钮：在 Finder 显示 / 卸载（危险样式）。
- **卸载确认页（重点设计）**：这是信任关键页。展示主体应用 + 按位置分组的残留文件清单（Application Support / Caches / Preferences / 启动项…），逐项路径与大小、全部默认勾选可取消；底部合计"共 N 项，X.XX GB，将全部移入废纸篓"；确认按钮为危险色。多选批量卸载时该页支持多应用分节。
- **残留 tab**：已卸载应用留下的孤儿文件，按"疑似所属应用"分组（灰色虚线描边的幽灵图标表示应用已不存在），交互同清理确认。

### 页面 4：优化

**功能**：系统维护任务清单，先解释后执行。

- **清单态**：任务卡片按四个分区排列：日常维护 / 修复小毛病 / 深度维护 / 体检报告（只读审计类）。每张卡：图标、任务名、一句话说明、预估时长、需要管理员权限时的钥匙徽标；卡片可展开"会做什么"详情（具体命令级描述）。顶部：推荐组合快捷选择（全部日常/全部修复）+ "执行已选 N 项"主按钮。
- **执行态（重点设计动画）**：页面转为专注模式——焦点视觉体（优化页主题色的脉冲环形态）+ 标题"正在优化系统" + 当前任务名与进度"4/23"；下方任务清单流：已完成项打钩收拢、当前项高亮呼吸、待执行项半透明。任务逐个完成时对钩要有绘制动画（stroke 动画 ~300ms）。
- **完成态**：结果摘要，每个任务给具体结果文案（如"DNS 缓存已刷新""清理了 14 个失效登录项"）；skipped 项如实展示原因（如"需要管理员权限"）。
- 需设计：管理员权限任务的授权引导弹层（说明 helper 是什么、只做什么）。

### 页面 5：分析

**功能**：磁盘空间可视化，Treemap + 目录列表双联动。

- 布局：左栏（约 300pt）为当前目录条目列表：名称、大小、水平占比条、可清理项有主题色小圆点标记；主区为 **Squarified Treemap**。顶部：面包屑路径（可逐级点击回退）+ 当前层总量 + 右侧整盘容量条（已用/总量）。
- Treemap 规则：块内显示名称+大小（小块只显示 tooltip）；目录块按层级做同色系深浅变化，"可清理"块用主题强调色；hover 提亮 + 阴影抬升 + tooltip（完整路径/大小/最后访问时间）；单击下钻（**需设计下钻转场**：被点击块放大铺满 → 内部子块级联浮现，~350ms；返回为逆过程）；右键菜单：在 Finder 显示 / 移到废纸篓 / 添加到白名单。保护路径的块：删除项禁用并说明。
- 扫描进行中的骨架态：块从模糊占位逐渐清晰、大小渐进收敛，右上角小型进度指示（已扫文件数/字节数滚动）。
- 第二个 tab"大文件"：全盘 Top 大文件列表，行内直接可 Trash。
- 空态与首扫引导：首次进入的 overview 快照视图（用户目录/应用/资源库等一级大块）。

### 页面 6：状态

**功能**：只读系统健康仪表盘。

- **卡片网格**（两行四列，可随窗口宽度回流为 2×4）：
  - 健康分卡（占位更大）：0–100 大数字 + 状态短语（如"CPU 负载偏高"）+ 硬件徽标（芯片型号/内存/系统版本）+ 运行时长。健康分数字颜色随分数插值（绿→琥珀→红）。
  - CPU：使用率大数字 + 温度徽标 + 近 60 个采样的柱状历史图；GPU：使用率+温度；内存：压力百分比 + 使用量/交换空间 + 面积图；磁盘：可用空间 + 容量渐变条；网络：实时上下行速率 + 双色 sparkline；电池：电量、循环次数、健康度、功率；风扇：转速 RPM。
  - 所有实时数值用滚动补间；曲线/柱状图新数据点从右侧平滑推入。
- **进程表**：名称+图标、PID、CPU（含微型条形）、能耗、内存；列头可排序（当前排序列高亮+方向箭头）；持续高 CPU 的进程行首有火焰徽标；行尾"…"菜单：结束进程（需二次确认弹层，设计该弹层）、在活动监视器中打开。
- 顶部右侧：刷新率切换（1s/2s/5s 小分段控件）。
- 需设计：数据流断连时的"重连中"状态（卡片数值变灰 + 顶部细提示条，不允许直接冻结假装正常）。

### 页面 7：历史（从导航右侧图标进入）

- 按操作会话分组的时间线："7月6日 14:32 · 清理 · 释放 8.9 GB · 129 项"，展开显示逐项路径与大小；条目动作：在废纸篓中显示、恢复此项（v1.1）、复制路径。
- 空态插画 + "还没有清理记录"。

### 页面 8：设置

- 标准 macOS 设置样式，左侧分区：通用（语言/启动页/刷新率）、白名单（列表+添加路径+删除，说明"两端与命令行版共用"）、权限中心（FDA 状态卡 + helper 状态卡，含已授权/未授权两种状态样式与跳转按钮）、高级（诊断日志导出）、关于（版本、内嵌核心版本、开源许可）。

### 页面 9：首次启动引导（Onboarding，三步）

1. 品牌页：徽标 + 三承诺（可预览/进废纸篓/有记录）三图标横排 + "开始"。
2. 完全磁盘访问：插画说明为什么需要 + "打开系统设置"按钮 + 实时检测状态（未授权=琥珀点脉冲"等待授权…"；检测到授权瞬间变绿色对钩 + 自动进入下一步的成功微动效）。
3. 可选管理员组件：说明只影响少数深度维护任务，"安装 / 跳过"双按钮，跳过无压力感设计。
- 三步间用水平滑动转场 + 底部步骤指示点。

## 四、动画系统（最高优先级需求，请单独成章交付）

我们要求清理/优化过程的动画**流畅、酷炫、有记忆点**，这是产品体验的灵魂。请为以下动效逐一给出：视觉描述、时长、缓动曲线、触发条件，并保证整套动效语言统一。

### 4.1 焦点视觉体（Focus Orb）状态机

设计一个贯穿智能扫描/清理/优化页的核心动效资产，至少包含五个状态及状态间过渡：

1. **静息**：缓慢呼吸（缩放 ±2%，周期 4s）+ 粒子微漂移，安静但活着。
2. **扫描中**：粒子/线条进入环绕流动，转速与扫描进度轻微正相关；球体表面有扫描波纹周期性掠过；发现大体积可清理项的瞬间，球体轻微膨胀脉冲一次 + 一圈涟漪光环扩散（与"已发现 X GB"数字上翻联动）。
3. **等待确认**：流动减速至缓慢自转，色温变稳，暗示"结果已就绪"。
4. **执行中**：最酷炫的阶段——每清理完成一项，从日志区方向有一缕粒子流被"吸入"球体（或从球体剥离飘散消解，二选一并说明理由）；整体节奏跟随清理速度，快速连续完成时粒子流形成连贯的溪流感；球体核心亮度随累计释放空间缓慢增强。
5. **完成**：收束动画——粒子向核心聚拢 → 定格一瞬 → 绽放为一圈干净的光环扩散 + 大数字结果浮现（弹性入场）。整段 ~1.2s，要有"仪式感"但不拖沓。

### 4.2 其他关键动效清单

- 数字滚动补间（所有动态数值，300–500ms，easeOut）。
- 结果日志逐行滚入（新行从下方 8pt 淡入上移，120ms）。
- 卡片级联入场（60ms stagger，浮起 + 淡入）。
- 导航胶囊高亮位移（spring）。
- Treemap 下钻/回退转场（§页面5）。
- 任务对钩 stroke 绘制动画。
- 页面切换：内容区交叉淡入 + 4pt 轻微位移，250ms，禁止大幅滑动。
- 状态图表数据点推入动画。
- 危险操作按钮按下时的确认微交互（如按住 0.4s 填充确认，或二次确认弹层，给出你的方案）。

### 4.3 动效原则

- 所有动效必须服务信息传达（进度、因果、层级），禁止纯装饰性长动画阻塞操作。
- 单次交互反馈 ≤200ms；转场 ≤400ms；焦点视觉体为环境动画不阻塞任何点击。
- 需给出"减弱动态效果"（Reduce Motion）开启时的全套降级方案（呼吸/粒子停用、转场改纯淡入淡出、保留数字补间）。

## 五、交付物要求

1. **设计系统页**：色板（深/浅双模式全 token）、字号阶梯、间距体系、圆角与阴影规范、全部通用组件的多状态展示（default/hover/pressed/disabled/selected）。
2. **九个页面的高保真设计**：深色模式全量；浅色模式至少覆盖智能扫描、清理结果确认、状态页三个代表页。
3. **关键流程的多状态帧**：清理页四状态、优化页三状态、Onboarding 三步、卸载确认页，均需完整呈现（不能只画理想态）。
4. **边界状态**：空状态、加载骨架、错误卡片、无 FDA 权限横幅、断连重连、零结果（"没有可清理的内容，你的 Mac 很干净"——这个状态要设计得令人愉悦）。
